Bundestagswahl 2025: election programs as word vectors

A separate Word2Vec model was trained on each of the four election programs. For a political term, each model returns the words that occur in the most similar contexts in that program. Comparing these neighbours shows in which context each party uses the term.

      The corpora

      Tokens are the lemmas that remain after removing stop words, punctuation and numbers. The vocabulary contains every lemma with at least 3 occurrences.

      How it works

      Word2Vec skip-gram with negative sampling, as implemented in gensim.

      Limitations

      • Each program has only 12,000 to 23,000 tokens; general-purpose embeddings are trained on billions. The neighbours are indications of how a party uses a term, not proof of intent.
      • Models trained with different random seeds return partly different neighbours. The page therefore averages over several seed models and marks neighbours that only some of them return.
      • Similarity values are comparable within a party. Across parties, compare the neighbours, not the exact values: each model has its own vector space.
      • Similarity means "used in similar contexts". Opposites (e.g. "erhöhen" and "senken") often have high similarity.
      • Lemmatization by spaCy's small German model contains errors, e.g. "Lehrerinnen" becomes "lehrerinne".
      Data: election programs of CDU/CSU, Bündnis 90/Die Grünen, SPD and AfD for the Bundestag election on 23 February 2025. Code and models under the MIT license on GitHub.
